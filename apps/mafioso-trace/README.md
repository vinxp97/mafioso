# Mafioso Trace

A macOS viewer for the harness JSONL trace. The schema is [docs/TRACING.md](../../docs/TRACING.md). The app is a local dev tool. App Sandbox is off so it can read `~/mafioso-mac/logs`.

`MafiosoTraceCore` is the parser and the file tail. It has no SwiftUI. `swift test` in that package is the behavior check, and it can run on Linux. The app target is macOS 14 or later. `MafiosoTrace.xcodeproj` is generated by XcodeGen and is not in git.

```bash
cd apps/mafioso-trace/MafiosoTraceCore && swift test
bash scripts/build-trace-app.sh
```

`scripts/build-trace-app.sh` needs `xcodegen` (`brew install xcodegen`). It generates the project, then builds Debug with ad-hoc signing and no team. The product is `apps/mafioso-trace/build/Build/Products/Debug/MafiosoTrace.app`.

Open a sample game without a live log:

```bash
apps/mafioso-trace/build/Build/Products/Debug/MafiosoTrace.app/Contents/MacOS/MafiosoTrace \
  -fixture apps/mafioso-trace/Fixtures/sample-game.jsonl
```

The fixture is synthetic. The names are Ada, Bea, Cal, Dee, and Eli. Cmd-R reloads. Settings changes the logs root. The default is `~/mafioso-mac/logs`.

The sidebar is one row per game directory. A game whose files changed in the last 15 seconds is marked live. The app opens on seat All and phase All. Choosing a row does not change those filters. The detail column is a timeline and the selected event. The scrubber and the `n / N` counter stay on the selected row. Reasoning is monospaced text you can select. An `llm.call` shows Proposal vs Verdict at the top: the parsed proposal beside the engine verdict with the same `callId`. Follow scrolls to the new line until you pick an older row or turn Follow off. A finished game can be scrubbed with the slider when more than one event is visible. Zero or one event shows the position label only.

Lines are read a chunk at a time on a background task. The window keeps parsed events, not the file text.
